# Category Images

Drop one photo per category here. Each photo is used as:
- The full hero banner on the category page
- The thumbnail image on every essay card in that category
- The visual on the homepage collection cards

## Files needed

| File | Category |
|---|---|
| `opportunity.jpg` | Opportunity essays |
| `india.jpg` | India essays |
| `odisha.jpg` | Odisha essays |
| `travel.jpg` | Travel essays |
| `future-of-work.jpg` | Future of Work essays |
| `entrepreneurship.jpg` | Entrepreneurship essays |
| `philosophy.jpg` | Philosophy essays |

## Photo tips

- Landscape orientation works best (wider than tall)
- Minimum 1200px wide for crisp display
- JPG or PNG both work
- The image will be cropped to fit — centre the subject
- Dark images work especially well (text overlays are white)
